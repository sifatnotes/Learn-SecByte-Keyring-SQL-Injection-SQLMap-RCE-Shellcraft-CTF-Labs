## Learning Path

A practical progression through this collection is:

1. Begin with **Keyring Source Sleuth** to practice source-code investigation.
2. Continue with **Hidden Endpoints Keyring Hunt** and **Keyring Function Hunter** for application enumeration.
3. Study **Keyring SQLi Discovery** and **Injection Signal** to understand SQL injection discovery.
4. Explore **SQLMap Keyring Break-In** to practice automated SQL injection assessment in the lab.
5. Move to **Keyring Access Reuse** to study access-related concepts.
6. Continue with **Keyring RCE Vault** and **Keyring Leak Shell** for RCE and shell-oriented challenges.
7. Practice **Keyring Shell Stabilization** and **Keyring Shellcraft** to understand shell handling.
8. Finish with **Keyring Post-Exploitation Forge** for post-exploitation concepts.

## How to Use the Labs

- Read the instructions for each CTF lab before beginning.
- Use all techniques only against the authorized lab environment.
- Keep notes about endpoints, source-code findings, injection points, and application behavior.
- For SQL injection labs, understand the underlying vulnerability rather than relying solely on automation.
- For SQLMap exercises, learn what the tool is testing and why.
- For RCE and shell labs, document the security concept demonstrated by the exercise.
- Treat credentials, keys, and other discovered information as lab-only data.
- Never reuse discovered credentials or techniques against systems without explicit authorization.
